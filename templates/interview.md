# Structured interview — 20 minutes

Use the same core questions for every candidate.

- Introduction: 2 minutes.
- Technical: 6 minutes. Investigate a Java memory leak; explain Spring Boot dependency injection; explain consistent API error handling.
- Scenarios: 6 minutes. Investigate a production API timeout; investigate a slow SQL query.
- Collaboration: 3 minutes. Describe resolving a technical disagreement.
- Candidate questions and close: 3 minutes.

Record evidence before rating: 1 = no relevant evidence after standard follow-up; 2 = partial detail; 3 = workable approach and steps; 4 = specific example and trade-offs; 5 = reasoning, verification and alternatives.

Skipped competency: **not assessed**, never automatically zero.
