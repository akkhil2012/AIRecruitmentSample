# Joining and exit plans

| Stage | Task | Owner | Approval / completion evidence |
|---|---|---|---|
| Joining | Verify documents | HR | Authorized HR confirmation |
| Joining | Induction and first-week plan | Manager | Approved schedule |
| Joining | Role-appropriate IT access | IT | Approved request and completion record |
| Exit | Handover | Manager | Handover acceptance |
| Exit | Asset return | IT | Asset receipt |
| Exit | Access revocation | IT | Authorized request and revocation confirmation |

Authorized HR verifies terms and approvals before releasing an offer. Authorized HR, legal and IT staff execute the actions they own. These are plans, not execution records.
